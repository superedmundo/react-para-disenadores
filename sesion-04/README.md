# Sesión 04 — Componer con Flexbox

## Pregunta central

**¿Cómo organizamos y alineamos elementos dentro de una interfaz?**

## Objetivo

Utilizar Flexbox para organizar varias piezas dentro de un contenedor.

## Aprendizaje esperado

Al terminar podrás:

- identificar un contenedor;
- crear una fila;
- crear una columna;
- usar `gap`;
- modificar una alineación o distribución;
- explicar qué propiedad cambió la composición.

## Idea principal

```text
Flexbox = cómo se organiza un grupo
```

## Qué carpeta abrir

1. `inicio/` — observa el problema.
2. `demo/` — sigue la demostración.
3. `ejercicio/` — realiza la práctica.
4. `solucion/` — consulta después de intentar.
5. `assets/` — contiene el recurso visual.

Abre `index.html` en el navegador y edita `styles.css`.

## Conceptos

```css
display: flex;
flex-direction
gap
justify-content
align-items
```

## Experimentos

En `.galeria`:

1. cambia `row` por `column`;
2. prueba `gap: 8px`, `24px` y `48px`;
3. prueba `justify-content: flex-start`, `center` y `space-between`;
4. cambia `align-items`.

Después de cada cambio:
- guarda;
- observa;
- identifica qué propiedad produjo el efecto.

## Ejercicio

Organiza una mini galería de tres tarjetas.

Debes:
- localizar `.galeria`;
- activar Flexbox;
- elegir fila o columna;
- utilizar `gap`;
- cambiar una alineación o distribución.

## Resultado mínimo

La interfaz muestra tres tarjetas organizadas por un contenedor Flexbox y puedes explicar qué hace al menos una propiedad de alineación.

## Extensión opcional

Haz una segunda versión cambiando solamente dirección, `gap` y alineación. Compara cuál funciona mejor.

  2. ¿Qué hace `flex-direction`?
  3. ¿Qué propiedad usaste para alinear o distribuir?
